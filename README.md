# True Force Security Website

Premium security agency website built with **React + Vite**.

---

## 🚀 Quick Start (First Time Setup)

### Prerequisites
Make sure you have **Node.js** installed:
👉 Download from [https://nodejs.org](https://nodejs.org) (LTS version recommended)

### Option 1 — Double Click (Easiest)
Just double-click **`start-website.bat`** in this folder.
It will automatically install dependencies and open the browser.

### Option 2 — Manual (Command Line)
Open a terminal in this folder and run:

```bash
# 1. Install dependencies (only needed once after cloning)
npm install

# 2. Start the development server
npm run dev
```

Then open your browser at: **http://localhost:5173**

---

## ⚠️ Common Issues

| Problem | Fix |
|---|---|
| `npm` not found | Install Node.js from https://nodejs.org |
| Site not loading after `npm run dev` | Wait 5–10 seconds, then open http://localhost:5173 |
| Port 5173 already in use | Close other terminals, or restart your PC |
| Opening `index.html` directly | ❌ This won't work — always use `npm run dev` |
